PUT YOUR RVC MODEL FILES HERE!

1. Download an RVC Voice Model (usually a .zip file).
2. Extract it.
3. Look for a `.pth` file (e.g., `Goku.pth` or `MyVoice.pth`).
4. Place that `.pth` file in this folder.
5. (Optional) If there is an `.index` file, put it here too for better quality.

The Dubbing Service will automatically find the first .pth file and use it to clone the voice!
If this folder is empty, it will use the high-quality Edge TTS voice (Tier 1).
